# report-html-b — 報告版型 風格 B（v3 定稿）產生器（skill v1.9）

這個 skill 做一件事：**讀使用者給的材料 → 填一份 `報告內容.md`（文字 ＋ 圖表宣告 ＋ 數字）→
`scripts/build.py` 產出單檔 HTML → `scripts/qa_html.py` 全綠 → 交付**。

版型與視覺已由 Lena 在 2026-09-10／09-14 定案並鎖死（見第 5 節）。**不要問使用者要不要改配色、字級、
版面；也不要新增圖表類型。** 你的工作是把內容填對、把資料整理成宣告要的形狀。

路徑一律相對於本 skill 資料夾（SKILL.md 所在處）。先讀 `references/圖表與數值宣告格式.md`
的第 1～6 節再開工；寫章節文字時對照 `references/內容檔格式說明.md`。

---

## 1. 什麼時候用、什麼時候不用

用：
- 使用者要「把這個專案的分析做成 HTML 報告」「用 Lena 的版型出一份」「風格 B」。
- 材料是下列任一或混合：跑完的 `.ipynb`（含 outputs）、`.csv`、寫好結論的 `.md`／`.txt`。

不用（先講清楚再停）：
- 要的是 xlsx／pptx／PDF 原生格式（HTML 可以「列印成 PDF」，但不是 PDF 產生器）。
- 要改版型設計（顏色、字級、版心、目錄行為、互動）——回答「這些是鎖定的設計決定，改要走
  Claude Code 那條線」，不要動 `themes.py`／`rhtml.py`。
- 要的圖不在 14 種支援類型內（第 3.2 節）——說明目前不支援，改用最接近的類型或 ```` ```table ````。**不要自己加新 type**（加圖型走 Claude Code 那條線，見 `references/圖表與數值宣告格式.md` §8）。

## 2. 前置條件

- Claude Desktop 的**程式執行**（code execution）要開著；只需要 Python 3.8+ 標準庫。
- 只讀**對話裡提供的材料**（上傳的檔案、貼上的文字、指定的資料夾）。不連網、不查資料庫、
  不憑印象補數字。材料裡沒有的數字就留 `〔待補〕` 並在交付時列出。
- 產出的 HTML 要存到**可下載的輸出位置**：`/mnt/user-data/outputs/`（Claude 程式執行環境的
  可下載資料夾）。沙箱沒有這個路徑時存到工作目錄 `out/` 並把檔案呈現給使用者。

## 3. 流程（照順序做，不要跳）

### 3.1 盤點材料

```bash
python3 scripts/inspect_inputs.py <使用者指定的資料夾或檔案們> --rows 5
```

它會列出每個檔案能用的東西。三種材料各自怎麼轉：

| 材料 | 拿什麼 | 轉成什麼 |
|---|---|---|
| `.ipynb` | code cell 的 `execute_result`／`display_data` 表格（pandas HTML）、`text/plain` 結果、`print` 出來的結論；markdown cell 的標題與結論句 | 表格 → 存成 `data/*.csv` 當圖或表的資料；單一數字 → 檔頭 `values:`；結論句 → 本章結論／判讀／結論卡。**圖片 output 只當參考**（看它畫了什麼），報告的圖一律用宣告重畫 |
| `.csv` | 欄位與列 | 直接當圖表資料：時間序列 → `line`；類別 × 一個數值 → `bars`；類別 × 2～3 個數值並排比較（前／後、族群 × 指標）→ `grouped`；類別 × 2～5 段同一總量的組成（人數、金額，皆 ≥ 0）→ `stacked`；類別 × 兩段拆解 → `ranked`；占比列 → `stacked100`；天數位移（day／D1…）× 幾群留存率 → `retention`；cohort × 天數位移的留存率（可有空格）→ `cohort`；步驟 ＋ 逐步遞減的人數 → `funnel`；其餘 → `table` |
| `.md`／`.txt` | 結論、建議、口徑、caveat | 前言 lede、結論卡、建議＋預期影響、附錄。**數字照抄前先對回 csv**，對不上就用 csv 的、並在 caveat 註明 |

盤點完先在心裡（或草稿）列一張表：**章 → 要回答的問題 → 用哪張圖（type）→ 資料來自哪個檔的哪幾欄 → 判讀一句**。
章數 3～5 章、每章 1～2 個圖表最順。

### 3.2 決定圖表類型（只有這 14 種圖，另加表格區塊）

| 問題 | type | 資料形狀（csv） | 對應 svgchart |
|---|---|---|---|
| 隨時間怎麼走、斷點前後差多少 | `line` | `x` 欄（日期）＋ 每條序列一欄；分位帶用 lo／hi 兩欄 | `xy_chart` |
| 總變化拆成幾塊（2～12 段，可插中繼小計） | `waterfall` | `items:` 直接列（水位／變化／中繼），段多可改吃 csv `name,kind,value` | `waterfall` |
| 組成前後對照（占比加總 100%） | `stacked100` | 每列一根條：`label`,`sub`, 各段占比欄 | `stacked100` |
| 誰貢獻最多（每根拆兩段） | `ranked` | `name`, 部分 1, 部分 2 | `ranked_bars` |
| 類別各自多少（含正負） | `bars` | 類別欄, 數值欄 | `vbars` |
| 幾群在 D1/D3/D7/D14/D30 的留存（可指定基準群） | `retention` | `day` ＋ 每群一欄（0～1 或 0～100） | `xy_chart`（點標記、類別 x 軸） |
| 類別 × 序列並排比較（底台 × 前後、族群 × 指標），每組可標 ▲▼ 變化 | `grouped` | 類別欄 ＋ 每序列一欄（2～3 條） | `grouped_bars` |
| 各步驟人數與轉換率、哪一步掉最多 | `funnel` | `step,count`（人數逐步遞減） | `funnel` |
| 多期／多類別的組成怎麼變、柱高＝合計（絕對值，不是占比） | `stacked` | 類別欄 ＋ 每段一欄（2～5 段，值 ≥ 0） | `stacked_bars` |
| 各 cohort 在 D1／D3／D7…的留存，年輕 cohort 可缺後面的天數 | `cohort` | `cohort`（＋可選 `size`）＋ 每個天數一欄 `D1,D3,D7…`，空格＝尚未觀察到 | `heatmap` |
| 某指標的分布長什麼樣、p50／p90 落在哪（可比 2 組） | `hist` | raw 值：一欄數值（＋可選組別欄，≤ 2 組）；或已分箱 `bin_start,bin_end,count` | `histogram` |
| 每群前後兩個值與變化（底台 × 上線前後、族群 × 改版前後，≤ 20 組） | `dumbbell` | `群組欄, 前測欄, 後測欄` | `dumbbell` |
| 指標在星期 × 小時怎麼分布（作息、排檔期、活動時段） | `dow_hour` | long `dow,hour,value`；或 wide：`dow` ＋ 24 個小時欄 | `heatmap` |
| 幾個指標 × 幾個分組的檢定強度（哪格顯著、哪格沒做） | `sigheat` | 指標欄 ＋ 每個分組一欄，值＝非負統計量（\|t\|／-log10(p)），空白＝沒做檢定 | `heatmap` |
| 指標對照、前後檢定結果（要列 p 值、信賴區間的原始數字）、結論表 | ```` ```table ```` | 表頭列 ＋ 每列一筆 | rhtml.Table |

**v1.7 也沒有新增圖表類型**，多兩項能力（一樣是「宣告才生效」，不宣告＝輸出與 v1.6 逐 byte 相同）：

| # | 能力 | 怎麼開 | 說明在哪 |
|---|---|---|---|
| 1 | 折線圖例搬到 x 軸下方 | `line` 的 `legend: bottom` | 宣告格式 §4.1 |
| 2 | 結論改純條列（可有一層 `　◦ ` 子項） | 檔頭 `conclusion_style: list` | 內容檔格式說明 §6 |

`legend: bottom` 會把右邊界從 158px 縮成 26px（繪圖區變寬約 130px）、下邊界加高 46px 放一條橫排圖例；
**圖的總高度 `height` 不會自己變**，要維持原本的繪圖區高度就把 `height` 加 46。事件線的 warn icon
與事件標籤掛在繪圖區底緣，不會掉進圖例帶。圖例元素的 class 與 `data-key` 都沒變，點一下切換序列照常可用。

`conclusion_style: list` 只換結論的呈現方式（`<ul class="bul">`），文字與 `[[key]]` 引用照舊；
`[dn]`／`[up]` 在條列模式只寫進 `class`、**不上色**（條列沒有卡片上緣那條色帶）。

第 2 項與第 3 項是**正交**的兩件事，可以分開用也可以一起用：`mark: max` 決定**哪一格**上色
（一組配對只標數值較大的那一格），`scale`／`levels` ＋ 每組的 `v` 決定**那一格多深**
（三階中性藍 `#d7e3ee`／`#b0c8db`／`#8baec9`）。只寫 `mark: max` ＝單一階只標一格；
只寫 `v` ＝兩格都標但依強度分深淺；兩個都寫＝只有較大那格上色、深淺依檢定強度。

欄位定義、每型範例、顏色角色：`references/圖表與數值宣告格式.md`。不確定就 `python3 scripts/build.py --types`。

### 3.3 整理資料到 `data/`

- 一張圖一個 csv（表格也各一個），UTF-8，第一列是欄名，**數字不要帶千分位逗號與單位**。
- 日期寫 `YYYY-MM-DD`（宣告裡用 `xfmt: md` 就會顯示成 `07-16`）。
- 占比用 0～1 或 0～100 都可以（每列加總要等於 1 或 100）。
- 留存曲線 csv：第一欄 `day`（1、3、7… 或 D1、D3…），其餘每欄一群，值 0～1 或 0～100（一份 csv 只能一種；拿不準就宣告 `scale: ratio`／`pct`）。還沒觀察到的 day 不要留空——把那個 day 拿掉。
- 漏斗 csv：只給 `step,count`，人數要逐步遞減；占第一步／占上一步由程式算，不要抄進 csv。
- 堆疊長條 csv：第一欄類別、其餘每欄一段（2～5 段），值一律 ≥ 0、不要帶千分位；合計由程式算，不要自己加一欄「合計」（有的話別放進 `segments`）。宣告順序＝堆疊順序（第一段在底）。
- cohort 熱圖 csv：第一欄 cohort 標籤（不可重複）、可選 `size` 欄、其餘欄名寫 `D1`／`D7`… 或整數；年輕 cohort 還沒到的天數**留空**（會畫成空白格，不是 0）。D0 恆為 100% 會撐開色階，宣告時用 `days:` 排除。
- 直方圖 csv：**raw 值優先**——一列一個觀測（一欄數值、要比兩組再加一欄組別，**最多 2 組**），分位數才會是精確值；
  已經在 SQL 分好箱就給 `bin_start,bin_end,count`（箱不可重疊、`count` ≥ 0，分位線會標明是箱內插補的估算）。
  自訂箱界 `edges:` 必須嚴格遞增；值超出範圍預設報錯，要併入兩端得明寫 `clip: true`。
- 啞鈴 csv：`群組欄, 前測欄, 後測欄`，一群一列、群名不可重複，**最多 20 組**（更多請拆圖或改表格）。
  變化由程式算（`mode: pct`／`diff`），不要自己加一欄「變化」；前測為 0 的列變化會顯示 N/A。
- 星期×小時熱圖 csv：long `dow,hour,value`（168 列）或 wide（`dow` ＋ 24 欄，欄名 `0`～`23` 或 `h0`～`h23`）。
  `dow` 寫 1～7（**1＝週一**）、Mon～Sun 或 週一～週日都認得；`hour` 是 0～23（24 要寫成 0）。
  **真的 0 就寫 0，沒資料才留空**（空格畫成留白、不算 0）；同一個星期×小時只能有一列，要合併先在 SQL `SUM`。
- 顯著度熱圖 csv：第一欄是指標名（列標籤，不可重複、不可空白）、其餘每欄一個分組（**至少 2 欄**）；
  值填**非負**的檢定強度（`|t|`、`-log10(p)`、效果量絕對值擇一，全圖同一種），**沒做檢定就留空**（空白畫成留白、不是 0）。
  不要填帶正負號的 t 值或 p 值本身（色階是「值越大越深」，p 值會反過來）；方向請寫在判讀或另配 `dumbbell`／`table`。
- 瀑布 csv（段多時才用）：`name,kind,value`，`kind` 是 `level`／`delta`／`subtotal`；
  `subtotal` 的 value 可留空由程式算。**起點 ＋ 各 delta 必須等於終點**，對不上會報第幾項。
- 表格 csv 的 cell 可以直接寫行內標記：`{{d:-12.1:%}}`（自帶 ▲▼ 與正負號）、`{{n:39.05:分}}`、`{{warn}}`（警示 icon）；
  要另外指定排序值寫 `顯示@@排序值`（例：`<0.001@@0.0005`、`N/A@@`）。含逗號的 cell 用雙引號包。
- v1.5 表格三個選用宣告（列號／欄號都**從 1 數**、指的是資料列不含表頭）：`sig`（檢定顯著兩格上底色，
  `dir: lr` 左右配對／`dir: tb` 上下配對，備註句引擎自動補）、`rowspan: [欄號…]`（相鄰同值真合併）、
  `row_groups: [每群列數…]`（群間 2px 粗線，加總＝資料列數）。**這三個會自動關掉該表的排序**，不要再寫 `sortable: true`
  （`dir: lr` 不受影響）。
- v1.9 表格多一個 `col_groups: [每群欄數…]`（由左往右、加總＝欄數）：把同一個指標的「前／後／變化%」框成一塊，
  **只畫群與群之間、最右邊不收線**。它綁的是欄不是列，所以**不會**關掉排序，可以跟 `sortable` 併用。
  只寫一群（畫不出線）或加總對不上都會報錯。建議判準：**欄數 ≥ 10 且表頭有兩組以上「同一指標的前／後」才加**，
  窄表或每欄都是獨立指標的表不要加（直線會變噪音）。
- v1.6 底色可以分深淺：`sig.pairs` 每一組加 `v:`（該組配對的檢定強度，非負，例 `|t|`／`-log10(p)`），
  並在 `sig` 下寫 `scale:`（是哪一種統計量）與 `levels:`（兩個切點，例 `[2.58, 3.29]`）。**固定三階、越深證據越強**；
  一組都不帶 `v` ＝ v1.5 的單一階。**每組都要帶 `v`，不能只帶一半**；填帶號 t 值或 p 值本身會報錯（色階是值越大越深）。
  底色只上在被比較的那兩個數值格，**不要上在 `{{d:…}}` 變化欄**（紅綠字壓在深底色上對比不夠）；
  原始統計量仍然要留一欄（`p 值`／`|t|`），底色只是輔助線索。
- 資料是從 notebook 表格抄出來的話，抄完**數一下列數與欄數**，再跟 notebook 對一次。

### 3.4 填 `報告內容.md`

1. **檔頭**（`---` 之間）

   - `byline`：`數據分析一組 | Lena`（固定）。
   - `period`／`population`／`source`／`produced`：資料期間（含斷點與前後段天數）｜母體與 n｜來源（表名或 notebook 名）｜產出日期（今天，`YYYY-MM-DD`）。

   就排在卡片上方、之後就排在下方，編號是 `表 C-1`（C＝Conclusion，比照附錄的 A）。

4. **建議**：3～5 條 `- [立即／短期／長期] 動作`，**每條下一行必有 `預期影響：…`**（沒有會報錯）。不寫負責角色。
5. **每章**（`## 章名：一句話`）固定四段：
   `本章結論：一句` → 說明一句（為什麼這樣看） → ```` ```figure ````／```` ```table ```` 區塊（放哪圖就在哪） → 緊接 `判讀：一句`。

6. **附錄**（`## 附錄`，用 `###` 分子節；真的不要附錄就在檔頭寫 `appendix: false`，兩者不可並存）：口徑與母體／未驗證與已知瑕疵（**3～6 條 caveat**：沒實跑檢定、母體疑慮、樣本不足、無對照組、觀察窗未整週對齊…）／圖表色彩規則／互動說明。後兩節可以照抄模板。

| 警示 icon（v1.5） | `{{warn}}` ＝ inline SVG 紅色三角驚嘆號（`#c62828`、1em、帶 `.sr` 文字）；**不用 emoji**（`⚠` 會被 qa 第 16 項擋）、不引 icon 字型 |
| 折線事件線的 icon（v1.6） | `vlines` 的 `icon: warn` ＝ 與 `{{warn}}` **同一個形狀同一個紅**的 SVG path（24×24 viewBox 縮 0.62），畫在事件線**下端**（離 x 軸 7px）、事件標籤跟著移到下面；只有 `warn` 一種，不吃顏色參數（跟著 vlines 的 `color` 走，預設紅）。Lena 2026-09-16 要求「斷點要紅虛線＋warning icon、圖標放在圖下方」 |
| 檢定底色只標較大格（v1.6） | `sig` 的 `mark: max`；底色仍是**單一階** `#d7e3ee`，**不做色深分級**（Lena 2026-09-16 定案：維持單階，兩格比較只標數值大的那格）。數值相同時兩格都標；備註標準句自動換成「…配對中只標數值較大的一格」 |
| 結論區塊（v1.5） | 條狀卡片**仍是預設且不可取代**（至少一條）；額外可放 ```` ```table ````／```` ```figure ````，編號 `表 C-1`（C＝Conclusion，比照附錄 A），寫在第一張卡片前就排上方 |

## 6. 常見錯誤與怎麼讀報錯

報錯格式：`第 N 行：問題 → 提示`。行號是 `報告內容.md` 的行號（圖表區塊內的錯會指到區塊裡那一行）。

| 看到 | 原因 | 怎麼修 |
|---|---|---|
| `不認得的圖表類型 \`xxx\`` | type 打錯或想用不支援的圖 | 用這 14 種之一；不合就改成 table |
| `第 N 列的 \`新客\` ＝ 1.2，超過 1（0~1 比例口徑）` | 留存率超出範圍，或比例／百分比混用 | 清資料；資料是百分比寫 `scale: pct` |
| `「坐下」的人數 90,000 比上一步 … 多——漏斗每一步不能比上一步多` | 步驟順序或口徑錯 | 排對順序／去重；資料本來就回升才寫 `allow_increase: true` 並在 note 說明 |
| `分群長條至少要兩條序列`／`最多 3 條序列` | 序列數不對 | 1 欄改 `bars`；>3 拆圖或改表格 |
| `第 N 列的 \`自然新客\` 是負的（-9900）——堆疊長條的段不能是負值` | 絕對量出現負數 | 有正負的量改 `bars`／`grouped`；或改口徑 |
| `堆疊長條最多 5 段` | 段太多 | 小段合併成「其他」或改表格 |
| `堆疊長條的 y 軸要從 0 起` | `ymin` 寫了正數 | 拿掉 `ymin`（柱狀量不截斷） |
| `delta 的 b \`2026-09\` 不是任何一個類別` | 堆疊長條的 delta a／b 要寫 x 欄的值 | 照提示的類別改 |
| `天數欄重複：D7 同時出現在 \`D7\`、\`7\`` | cohort csv 兩欄是同一天 | 留一欄 |
| `第 N 列的 cohort \`2026-W30\` 與第 M 列重複` | cohort 標籤重複 | 合併成一列或改標籤 |
| `欄 \`region\` 不是天數欄` | cohort csv 有非天數欄 | 人數欄用 `size:` 指名；其他欄用 `days:` 挑掉 |
| `{{v:xxx}} 算不出來：選到的範圍有缺值（空白格）` | 計算式踩到 cohort／星期×小時熱圖的空白格 | 用 `from`／`to` 限定已完整觀察的範圍；熱圖全日合計改用 `total` 欄 |
| `第 N 列的 \`count\` 是負的（-120）——人數不能是負數` | 直方圖 count 欄抄到差值 | 給人數欄；有正負的量用 `bars` |
| `直方圖疊圖最多 2 組（\`group\` 有 3 組）` | 組別欄超過兩組 | 只留要比的兩組、拆成多張圖，或改 `grouped`／`table` |
| `edges 要嚴格遞增：第 k 個 … ≥ 第 k+1 個 …` | 箱界寫反或重複 | 由小到大排好，不可重複 |
| `有 N 筆值超出 edges 範圍 …` | raw 值超出自訂箱界 | 把 `edges` 兩端拉開，或寫 `clip: true` 併入兩端 |
| `資料裡沒有 b 欄 \`上線後\`` | 啞鈴的 `a:`／`b:` 欄名跟 csv 不合 | 照提示的欄名改；`b:` 必填 |
| `啞鈴圖最多 20 組（現在 N 組）` | 列太多 | 拆成兩張圖，或只留變化最大的 20 組、其餘改表格 |
| `瀑布最多 12 段（現在 N 段）` | 拆太細 | 小段合併成「其他」，或拆成兩張圖（先族群、再因子） |
| `第 N 項「…」是 level，值 … 與前面各段的累計 … 差 …` | 瀑布恆等式不成立 | 核對各段正負號與小數位；真的只是尾差就把終點改成 `kind: subtotal` |
| `第 N 列的 \`dow\` 是 '星期八'，不是合法的星期` | dow 值不合法 | 用 1～7（1＝週一）／Mon～Sun／週一～週日 |
| `第 N 列的 \`hour\` 是 '25'，小時要是 0～23 的整數` | 小時超出範圍 | 0～23；24 要寫成 0 |
| `delta 的 b \`xxx\` 不是任何一條序列` | delta 的 a／b 寫錯 | 照提示的序列名改 |
| `資料裡沒有 \`xxx\` 這一欄 → …的欄位：a、b、c` | series 的 col／x 跟 csv 表頭不一致 | 照提示的欄名改 |
| `data 檔找不到：data/x.csv` | 路徑相對於 md 所在資料夾 | 把 csv 放到 md 旁邊的 data/ |
| `第 N 列的 \`col\` 不是數字` | csv 有單位、千分位或空字串 | 清成純數字；缺值不要留空列 |
| `defs 缺 著色` | 備註三行不齊 | 補齊 維度／指標／著色 |
| `缺母體註腳` | 沒有 note、也沒有檔頭 note_base | 檔頭加 `note_base:` |
| `{{v:xxx}} 找不到這個數字 key → 是不是要打 …` | key 打錯或沒定義 | 照建議改，或 `--keys` 看全部 |
| `用 seg: pre 之前，這張圖要先宣告 break` | 計算式用了 pre／post 但圖沒有 break | 圖加 `break: <x 值>` 或改用 from／to |
| `\`判讀：\` 要緊接在 … 收尾 \`\`\` 下一行` | 判讀前面夾了別的段落 | 移到區塊收尾的下一行 |
| `對應 { 沒有用 } 收尾`／`縮排…` | 區塊裡的 YAML 寫壞 | 值裡有 `,` `:` `#` 時用雙引號包；縮排用空格 |
| `{{fig:xxx}} 這種寫法已停用` | 用了舊版佔位寫法 | 改成 ```` ```figure ```` 區塊放在那一行 |
| `圖表 \`xxx\` 宣告了但沒有被放進任何章節` | 區塊放在前言／結論／建議裡 | 移到章節或附錄 |
| QA `4 正向引用 FAIL：未被引用 [fig-xxx]` | 正文沒有 `[[xxx]]` | 在結論或判讀提到它 |
| `vlines 的 color 只能是 red／ink（現在是 'green'）` | 事件線顏色寫了別的值 | 只能 `red`／`ink`（或留空＝ink）；要別的顏色請改設計那條線 |
| `vlines 的 icon 只能是 warn（現在是 'danger'）` | 事件線 icon 寫了別的值 | 目前只有 `icon: warn`；不要 icon 就整個欄位拿掉 |
| `sig 的 mark 只能是 both（兩格都標，預設）或 max（只標數值較大的一格）` | mark 寫了中文或別的值 | 只有 `both`／`max`；底色只有一階，要色深分級請走設計那條線 |
| `sig 宣告了 mark: max，但第 N 列第 M 欄（…）的 'N/A' 讀不出數字，沒辦法比大小` | 配對的格子不是數字 | 給那一格加排序值（`顯示@@數值`），或把 `mark` 改回 `both` |
| `vlines.at \`2026-06-31\` 不在 x 欄裡` | 事件日期不是資料裡的 x 值 | 照 csv 的 x 值寫（日期要同格式），或把那天補進資料 |
| `第 N 列的 \`B 組\` 是負的（-3.2）` | 顯著度熱圖填了帶號 t 值 | 填絕對值 `\|t\|` 或 `-log10(p)`；方向寫在判讀或另配 `dumbbell` |
| `顯著度熱圖至少要兩個數值欄（現在 1 個）` | 只有一個分組欄 | 補第二個分組；真的只有一組請改 `bars`／`table` |
| `第 N 列的 \`B 組\` 不是數字` | 熱圖格子寫了 `n.s.`／`-`／`p<0.05` 這種字 | 沒做檢定就**留空**；有做就填數字 |
| QA `6 重點紅字 FAIL` | 同一段超過 3 個 `!!…!!`，或某一處的最終生效顏色不是重點紅 | 刪到三處以內；顏色那條要看是不是有 inline style 蓋掉 `.hl`（v1.11） |
| `sig 的 dir 只能是 lr（左右配對）或 tb（上下配對）` | dir 寫了中文或別的值 | `lr`＝同一列兩欄、`tb`＝同一欄兩列 |
| `sig.pairs 第 N 項的 b 9 不是 1~5 的欄號` | 配對指到表格外 | 列號欄號都從 1 數、不含表頭 |
| `rowspan 的 0 不是 1~5 的欄號（從 1 數）` | 欄號從 0 數了 | 提示會列出欄號對照（1=底台、2=分段…） |
| `row_groups 加起來是 7 列，但資料有 6 列` | 群組列數沒對上 | 由上往下每群幾列，加總＝資料列數 |
| `rowspan／row_groups 不能跟 sortable: true 併用` | 想同時要合併格與排序 | 拿掉 `sortable: true`（宣告就自動固定列序） |
| `xticks 與 xtick_every 只能擇一` | 兩個都寫了 | 要自己指定刻度就只留 `xticks` |
| `xticks \`2026-06-02\` 不在 x 欄裡` | 指定的刻度不是資料裡的 x 值 | 照 csv 的 x 值寫（日期格式要一致） |
| `檔頭 \`hints\` 要是 true／false` | 寫成「關」「否」 | 只有 `true`／`false` |
| `檔頭寫了 appendix: false，卻還有一節 \`## 附錄\`` | 兩種都寫了 | 二選一 |
| `{{warn:red}} 不吃參數` | 警示 icon 帶了參數 | 就寫 `{{warn}}` |
| QA `11 互動掛勾 FAIL`（表數對不上） | 表寫了 `sortable: false` 但沒有 rowspan／列群組 | 讓它可排序，或用 `rowspan`／`row_groups`（會帶 `data-fixed="1"`，QA 認得） |
| `defs 多了 \`母體\`——備註只能四列：維度／指標／著色 ＋ 母體` | `defs` 寫了第四個鍵 | 母體寫在檔頭 `note_base:` 與區塊 `note_extra:`；其餘補充併進三列裡（宣告格式 §3.1） |
| `sig.pairs 第 N 項的 v 是負的（-5.91）` | 填了帶號 t 值 | 填 `\|t\|` 或 `-log10(p)`；方向看 ▲▼ 與正負號 |
| `levels 要剛好兩個切點（三階），現在有 3 個` | 想自己調階數 | 階數固定三階（列印可辨性的硬限制）；只給兩個切點 |
| `levels 要由小到大且不相等` | 切點寫反 | 小的在前，例 `[2.58, 3.29]` |
| `table 的 sig 缺 \`scale\``／`table 的 sig 缺 \`levels\`` | 帶了 `v` 卻沒說是哪一種統計量、階界在哪 | 補 `scale: "\|t\|"` 與 `levels: [2.58, 3.29]`（引擎不猜，猜錯會誤導讀者） |
