## 留存曲線：新客 vs 老客，全體為基準

本章結論：示意資料裡新客 D1 {{v:新客D1}}、D30 {{v:新客D30}}，全程低於全體基準；老客 D30 仍有 {{v:老客D30}}。

`type: retention` 沿用時間序列的互動（十字準線、tooltip、點右側標註切換序列），x 為天數位移、每個資料點有空心圓標記；`baseline:` 指定的那條自動畫成墨色虛線。

```figure
key: ret
type: retention
title: 新客／老客 D1～D30 留存曲線（全體為基準虛線）
data: data/retention.csv
x: day
scale: ratio
unit: pct
nd: 1
xscale: category
series:
  - {col: 新客, name: 新客, color: s1}
  - {col: 老客, name: 老客, color: s2}
  - {col: 全體, name: 全體（基準）}
baseline: 全體
aria: 示意留存曲線：新客 D1 42.0% 掉到 D30 8.1%，老客 D1 68.5% 到 D30 37.5%；全體為墨色虛線基準。
desc: x 為天數位移（D1/D3/D7/D14/D30，等距類別軸），y 為留存率 %，自 0 起；每個資料點有空心圓標記，滑過看各群該天數值，點右側標註可切換序列。
note_extra: 口徑（示意）：Dn 留存 ＝ 註冊後第 n 天有登入的人數 ÷ 該群註冊人數
defs:
  維度: 天數位移 D1／D3／D7／D14／D30 × 三群（新客、老客、全體）
  指標: Dn 留存率（%）＝ 第 n 天回訪人數 ÷ 該群人數（csv 給 0～1 比例，圖上換成 %）
  著色: 深藍＝新客、淺藍＝老客；墨色虛線＝全體基準；空心圓＝資料點
```
判讀：新客 D1→D7 掉 {{v:新客D1到D7}}，之後斜率趨緩 → 示意上「前 7 天」是留存動作的窗口。


## 分群長條：底台 × 上線前後

本章結論：示意資料裡五個底台的變化率介於 {{v:最小變化率}} 與 {{v:最大變化率}}，只有 5000 底台上升。

`type: grouped` 是類別 × 序列的並排柱（擴充自 `bars`）：每組可選 `delta:` 在柱頂標 ▲▼ 變化（紅漲綠跌＋正負號，顏色不是唯一線索），上方圖例可點著切換序列，滑過任一柱看該類別全部序列。

```figure
key: grp
type: grouped
title: 各底台平均遊戲時間：上線前 vs 上線後（柱頂為變化率）
data: data/grouped.csv
x: 底台
series:
  - {col: 上線前, name: 上線前, color: s3}
  - {col: 上線後, name: 上線後, color: s1}
unit: 分
nd: 1
ylab: 分/人/日
delta: {a: 上線前, b: 上線後, mode: pct, nd: 1, label: 變化率}
aria: 示意分群長條：五個底台上線前後的平均遊戲時間，變化率 -9.1% 到 +5.2%，只有 5000 底台上升。
desc: 類別（底台）× 兩條序列並排，序列用中性藍深淺；柱頂的 ▲▼ 變化率是唯一用到紅綠的地方，並帶正負號；點上方圖例可切換序列，y 軸尺度固定不重算。
note_extra: 口徑（示意）：分/人/日，各底台上線前後各 14 日均值
defs:
  維度: 底台（100／500／1000／5000／10000）× 上線前／上線後
  指標: 平均遊戲時間（分/人/日）；變化率 ＝（後 − 前）÷ 前
  著色: 灰藍＝上線前、深藍＝上線後（類別是中性語意）；柱頂 ▲▼ 變化率：紅漲綠跌 ＋ 正負號
```
判讀：低底台掉、高底台持平或升 → 示意上下滑集中在低底台，真專案要再拆人數看是「人變少」還是「玩得少」。


## 漏斗：從開啟大廳到玩到 10 手

本章結論：示意漏斗 {{v:進場人數}} 進場、{{v:完成人數}} 玩到 10 手（整體轉換 {{v:整體轉換}}），最大流失在「坐下」那一步（{{v:最大流失}}）。

`type: funnel` 是新畫法：步驟由上而下的水平長條，長度 ＝ 占第一步比例；每步可選顯示人數、占第一步 %、占上一步 %（`show:`），流失最大的那一步用淡底與粗體強調、不靠顏色。

```figure
key: fun
type: funnel
title: 牌桌進場漏斗：開啟大廳 → 玩到 10 手
data: data/funnel.csv
step: step
count: count
unit: 人
show: [count, pct_first, pct_prev]
emph: auto
aria: 示意漏斗：開啟大廳 120,000 人、進入牌桌列表 84,000、坐下 39,000、玩一手 36,200、玩到 10 手 21,700；整體轉換 18.1%，最大流失在坐下（占上一步 46.4%）。
desc: 五步由上而下、左對齊，長度為占第一步比例；右側兩欄為占第一步與占上一步；流失最大的「坐下」整列鋪中性淡底、步驟名粗體，並在數字下標「最大流失」，不用紅綠。
note_extra: 口徑（示意）：同一批 uid 的 31 日內累計，各步去重
defs:
  維度: 五個步驟，由上而下（開啟大廳 → 進入牌桌列表 → 坐下 → 玩一手 → 玩到 10 手）
  指標: 人數（去重 uid）；占第一步 ＝ 本步 ÷ 第一步；占上一步 ＝ 本步 ÷ 上一步
  著色: 單色藍，長度＝占第一步比例；最大流失那一步以淡底＋粗體標示（位置與字級，不靠顏色）
```
判讀：「坐下」只留住上一步的 46.4% → 示意上先查牌桌列表到入座之間的門檻（底注、滿桌、載入時間）。


## 附錄

### 口徑與母體

三份 csv 都是手寫示意數字。留存曲線 csv 用 0～1 比例、宣告 `scale: ratio` ＋ `unit: pct`，圖上一律換成 %；分群長條的變化率由程式算（`delta:`），不是抄進來的；漏斗的占第一步／占上一步也由程式算，csv 只給 `step,count`。

### 未驗證與已知瑕疵

- !!全部數字都是示意假資料!!，不是任何真實遊戲的輸出，不可引用、不可做決定。
- 留存曲線不支援缺值：尚未觀察到的 day（例如太新的 cohort 沒有 D30）要把那個 day 從 csv 拿掉，不能留空格。
- 留存曲線 x 軸預設等距（`xscale: category`）；D1～D7 的斜率在等距軸上會被視覺放大，要照天數比例放請改 `xscale: value`。
- 分群長條的 ▲▼ 變化率只在 `delta:` 指定的兩條序列之間算；三條序列時要自己指定 `a`／`b`。
- 漏斗預設不接受「比上一步多」的步驟（會報錯）；資料本來就會回升的情境要寫 `allow_increase: true` 並在 note_extra 說明口徑。

### 圖表色彩規則

- 紅 `#c62828` ＝ 重點與「漲」；綠 `#2e7d32` ＝「跌」（東亞慣例）。紅綠只出現在分群長條柱頂的 ▲▼ 變化率，且一律帶正負號。
- 留存曲線的群、分群長條的序列、漏斗的條都是中性藍灰；漏斗的「最大流失」用位置（淡底）與字級（粗體）強調，不用顏色。
- 序列 ≤4 用直接標註（留存曲線右側）或圖例（分群長條上方）取代圖例框；不逐點標數字。

### 互動說明

留存曲線（[[ret]]）滑過出現十字準線並吸附到最近的 day，tooltip 顯示各群該天留存率，點右側標註可切換序列；分群長條（[[grp]]）滑過任一柱看該類別所有序列與變化率，點上方圖例可切換序列；漏斗（[[fun]]）滑過任一步看人數與轉換率。觸控裝置 tap 等同 hover；列印時互動層收掉、被關掉的序列強制顯示。
