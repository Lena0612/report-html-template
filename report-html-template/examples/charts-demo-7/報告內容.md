## 前言

這份樣張只驗證 skill v1.7 新增的兩項能力，數字全部是手造的示意假資料、不可引用。兩項分別是：折線圖的圖例從右側搬到 x 軸下方（`legend: bottom`）、結論從條狀卡片改成純條列（檔頭 `conclusion_style: list`）。

兩項都是**宣告才生效**：不寫 `legend`、不寫 `conclusion_style` 時，輸出與 v1.6 逐 byte 相同（八個舊樣張的 HTML md5 全部沒變）。

## 結論

- [dn] 兩個跌點各掉一階（{{v:跌幅1}}、{{v:跌幅2}}），圖例改排在 x 軸下方、繪圖區因此變寬（見 [[dau_ev]]）
　◦ 事件線的三角驚嘆號與標籤掛在繪圖區底緣，不受下邊界加高影響（見 [[dau_ev]]）
　◦ 圖例元素的 class 與 data-key 都沒變，點一下切換序列照常可用
- [dn] 結論改成條列之後，子項用 `　◦ ` 寫，排成巢狀清單、不再擠成一整段（見 [[quant_tb]]）
- 同一個指標前後各一列時，用 `sig` 的 `dir: tb` 上下配對、`row_groups` 把每一對隔開（見 [[quant_tb]]）

## 建議

- [立即] 序列超過 4 條、或右側標註互相疊住時，就改用 `legend: bottom`
  預期影響：繪圖區寬度多出約 130px，長序列的形狀看得更清楚
- [短期] 結論子項超過兩層時改寫成表格，不要再往下疊
  預期影響：條列只支援一層 ◦ 子項，再深的層次會讀不出結構

## 圖例搬到 x 軸下方

本章結論：宣告 `legend: bottom` 之後，右邊界從 158px 縮成 26px、下邊界多一條 46px 的圖例帶。

`xy_chart` 原本把序列名稱直接標在線的右端（等於一個可點的圖例），右邊因此要留 158px。v1.7 多一個選用欄位 `legend: bottom`：圖例改成橫排放在 x 軸刻度下方，右邊界縮回 26px，繪圖區跟著變寬。事件線的 warn icon 與事件標籤是掛在繪圖區底緣（`T + ph`）畫的，跟著繪圖框走、不會掉進圖例帶裡。


## 同指標前後各一列

本章結論：前後各一列時，檢定底色改成上下配對，每一對用粗線隔開。

同一個指標拆成「前」「後」兩列時，顯著底色的配對方向要從左右（`dir: lr`）改成上下（`dir: tb`），`mark: max` 一樣只標數值較大的那一格；`row_groups` 把每一對隔成一群，群與群之間畫一條 2px 粗線。用了 `row_groups`（或 `dir: tb`）的表就是固定列序、不提供排序。

```table
key: quant_tb
title: 分位數前後對照（每個指標前後各一列，上下配對）
columns: [類別, 指標, P10, P25, P50, P75, P90]
align: [left, left, right, right, right, right, right]
types: [text, text, num, num, num, num, num]
data: data/quant_tb.csv
rowspan: [1]
row_groups: [2, 2]
sig:
  dir: tb
  mark: max
  pairs:
    - {col: 3, a: 1, b: 2}
    - {col: 4, a: 1, b: 2}
    - {col: 5, a: 1, b: 2}
    - {col: 6, a: 1, b: 2}
    - {col: 7, a: 1, b: 2}
    - {col: 5, a: 3, b: 4}
    - {col: 6, a: 3, b: 4}
    - {col: 7, a: 3, b: 4}
defs:
  維度: 類別 × 指標（前／後各一列）× 五個分位，每個指標的兩列合併成一群
  指標: 每天取一次分位、前後各 28 日均值（示意）
  著色: 底色＝該分位前後經檢定顯著，只標數值較大的一格；同一對的兩列之間比大小
note_extra: 檢定為示意、未實跑；人均手數的 P10／P25 前後相同故不列入配對
```
判讀：每個指標的「前」「後」兩列之間用粗線隔開，底色落在同一欄裡數值較大的那一格（[[quant_tb]]）。
