看什麼：

- **檢定底色**：底色是中性藍亮度階 `#d7e3ee`，**不是紅綠**（紅綠在這版型是漲跌語意）。
  上色的是**一對**格子：`dir: lr` 左右相鄰（同一列的上線前／上線後），`dir: tb` 上下相鄰（同一欄的前段／後段）。
  底色只說「這兩格差異顯著」，**方向仍然看 ▲▼ 與正負號**。備註最後那句
  「底色著色為經統計檢定有顯著差異，方向為左右／上下著色」是**引擎自動補的**，內容檔一個字都沒寫。
- **合併格與列群組**：底台欄是真的 `rowspan="2"`（不是留空），第一欄自動帶 `scope="rowgroup"`；
  三個底台之間是 2px 粗線。這張表**沒有排序功能**——排序會把合併格與群組打散，所以宣告這些就自動固定列序
  （HTML 上帶 `data-fixed="1"`，`qa_html.py` 第 11 項認得）。
- **x 軸刻度**：資料是每週一筆共 20 筆，用預設的「每 7 個標一次」會標到 5/1、6/19、8/8；
  `xticks` 指定成每個月 1 號（不等距），x 軸就只有 05-01／06-01／07-01／08-01 四個刻度。
- **警示 icon**：`{{warn}}` 是 inline SVG 紅色三角驚嘆號，**不是 emoji**（`⚠` U+26A0 會被 qa 第 16 項擋）。
- **結論表**：`表 C-1` 排在結論卡上方（因為區塊寫在第一張卡片之前）。卡片仍然是預設、沒有被取代。
