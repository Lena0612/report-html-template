## 前言

這份是 skill v1.4 兩個新東西的樣張：折線的**多條事件虛線 `vlines`**，以及新圖型**顯著度熱圖 `sigheat`**。!!所有數字都是手寫的示意假資料!!，只用來看宣告怎麼寫、圖長什麼樣。兩章各放一張圖，附錄列宣告時常踩的坑與兩者跟既有圖型的分工。


## 結論

- 示意 DAU：活動前四天平均 {{v:活動前均}}，活動期間最高 {{v:活動期最高}}；三條事件虛線（活動開始／伺服器異常／活動結束）直接標在圖上，不切前後段（[[dau]]）。
- [dn] 示意異常日：06-12 掉到 {{v:異常當日}}，對前一日 {{v:異常跌幅}}；那條虛線是**紅色**，其餘兩條是中性墨色——顏色只有這兩種。
- 示意檢定：新客側最強的 |t| 是 {{v:新客最強}}（日均遊戲時間）、老客側 {{v:老客最強}}（單局時長），色深只代表證據強弱、不代表變好或變壞（[[sig]]）。
- 示意缺格：回流組只跑了四個指標，另外兩格**留白＝沒有做檢定**（不是 0）；有跑的那格例如每日開局數 |t| ＝ {{v:回流開局數}}。
- 示意門檻：|t| ≥ 1.96 大致對應雙尾 p < 0.05，熱圖畫不出門檻線，所以門檻寫在 `defs` 的「指標」那行讓讀者自己對（新客留存 D7 是 {{v:留存新客}}，過線）。


## 建議

- [立即] 真專案套用 `sigheat` 時，先決定整張圖用哪一種統計量（|t|／-log10(p)／效果量絕對值）並寫進 `legend_title`
  預期影響：色階兩端是圖內 min／max，混用兩種統計量會讓深淺完全沒有意義

- [短期] 方向（變好還是變壞）另外配一張 `dumbbell` 或 `table`，不要想辦法塞進熱圖
  預期影響：熱圖只編碼強度，讀者不會把「色深」誤讀成「變差」

- [短期] 只有單一斷點、要做前後對比時用 `break` 不要用 `vlines`
  預期影響：`values:` 的 `seg: pre`／`post` 只認 `break`；用 `vlines` 冒充會在算數字時報錯


## 折線事件線：活動期間發生了什麼

本章結論：示意 DAU 在活動開始後拉高、伺服器異常當日掉到 {{v:異常當日}}，活動結束後七天回到 {{v:活動後均}}。

`vlines` 是 v1.4 給 `line` 加的欄位：每項寫 `at`（x 欄裡的值）、`label`（線旁文字）、`color`（只能 `red` 或 `ink`，不寫＝ink）。它跟既有的 `break` **不一樣也不衝突**：`break` 只能一條、會畫前後灰帶並定義 `seg: pre`／`post`；`vlines` 可以多條、只是事件標記，不畫灰帶也不影響任何計算式。這張圖刻意只用 `vlines`、沒有宣告 `break`，所以底下的數字全部用 `from`／`to` 指定日期範圍算。

```figure
key: dau
type: line
title: 日活躍人數與期間事件（三條事件虛線：活動開始／伺服器異常／活動結束）
data: data/dau.csv
x: date
xfmt: md
unit: 人
nd: 0
ylab: 人/日
ymin: 0
xtick_every: 3
height: 400
series:
  - {col: dau, name: DAU, label: DAU, color: raw, width: 1.4, order: 2}
  - {col: ma7, name: 7 日移動平均, label: MA7, color: s1, width: 2.8, order: 1}
vlines:
  - {at: 2026-06-05, label: 活動開始}
  - {at: 2026-06-12, label: 伺服器異常, color: red}
  - {at: 2026-06-19, label: 活動結束}
aria: 示意日活躍人數走勢：活動前約 12,200 人，活動開始（06-05）後升到最高 16,840 人，06-12 伺服器異常掉到 9,820 人（對前一日 -41.7%），活動結束（06-19）後衰退到月底約 12,150 人。
desc: x 軸為日期（06-01～06-30），y 軸為日活躍人數（人）、自 0 起未截斷。淡灰細線＝每日 DAU、藍粗線＝7 日移動平均。三條垂直虛線是事件標記：06-05 活動開始與 06-19 活動結束為墨色、06-12 伺服器異常為紅色；事件線不畫前後灰帶、不切段。
note_extra: 口徑（示意）：DAU ＝ 當日登入過的不重複 uid；MA7 ＝ 含當日往前 7 日的算術平均（前 6 日用可得天數）
defs:
  維度: 日期（2026-06-01～06-30，30 日）
  指標: 日活躍人數（人）與其 7 日移動平均
  著色: 淡灰細線＝每日 DAU、藍粗線＝MA7；垂直虛線＝事件標記，墨色＝一般事件、紅色＝負面事件（不代表數值方向）
```
判讀：活動結束後七天平均 {{v:活動後均}} 比活動前四天 {{v:活動前均}} 高不到一個百分點，月頭對月底 {{v:活動後對活動前}} → 示意上這檔活動沒有留下長期水位，異常日那一格是獨立事件、不是衰退起點。


## 顯著度熱圖：哪幾格有東西、哪幾格沒做

本章結論：示意檢定裡新客側的日均遊戲時間最強（|t| ＝ {{v:新客最強}}）、老客側是單局時長（{{v:老客最強}}）；回流組有兩格根本沒做檢定，留白。

`type: sigheat` 是 v1.4 新增：列＝指標、欄＝任意分組，格子填**非負**的檢定強度（`|t|`、`-log10(p)`、效果量絕對值擇一，全圖同一種），沒做檢定就**留空**。畫法沿用 cohort 熱圖那一支 `svgchart.heatmap`——單一藍色相亮度階、色盲安全、不用紅綠。跟 `cohort` 的差別是欄可以是任意分組（cohort 的欄只吃天數位移）；跟 `table` 的差別是有格子底色、一眼看得出哪裡有東西。

```figure
key: sig
type: sigheat
title: 各指標 × 各族群的檢定強度（|t| 越大證據越強；空白＝沒有做檢定）
data: data/sigheat.csv
row: 指標
cols: [新客, 老客, 回流]
legend_title: "|t|"
nd: 2
highlight_col: 新客
height: 300
aria: 示意顯著度熱圖：六個指標 × 三個族群的 |t|。新客的日均遊戲時間 4.81 最深、老客的單局時長 3.41 次之；回流族群的留存 D7 與 ARPDAU 沒有做檢定，留白。
desc: 列為六個指標、欄為新客／老客／回流三個族群；格底色為單一藍色相的亮度階（fill-opacity 0.08～1 對應圖內最小～最大 |t|），深色格改白字；空白格＝沒有做檢定不是 0；圖下方色階條標 min／max。色階只編碼證據強弱，不編碼方向。
note_extra: 口徑（示意）：兩樣本 Welch t 檢定的 |t|；p 值與方向未列在圖上，見判讀
defs:
  維度: 指標（6 列）× 族群（新客／老客／回流，3 欄）
  指標: 兩樣本檢定的 |t|（絕對值，全圖同一種統計量）；|t| ≥ 1.96 大致對應雙尾 p < 0.05
  著色: 單一藍色相亮度階，越深＝|t| 越大（色階條標 min／max，不用紅綠、不用彩虹）；空白＝沒有做檢定（不是 0）；新客欄標題加粗
```
判讀：過 1.96 的格子集中在新客的日均遊戲時間／留存 D7／單局時長與老客的單局時長／付費率 → 示意上要先看新客的前期體驗，但**方向要另外查**（熱圖只說差異大，沒說變好變壞）。


## 附錄

### 口徑與母體

兩份 csv 都是手寫的示意數字（沒有亂數，重跑一定一樣）。`dau.csv` 是 `date,dau,ma7` 共 30 列；`sigheat.csv` 是 `指標,新客,老客,回流` 共 6 列，其中回流欄有兩格故意留空。檔頭 `values:` 示範從兩張圖的資料算數字：折線用 `from`／`to` 指定日期範圍（因為沒有宣告 `break`，不能用 `seg: pre`／`post`）、熱圖用欄名取 max 或用 `from`／`to` 取單一指標那一列。

### 未驗證與已知瑕疵

- !!全部數字都是示意假資料!!，不是任何真實遊戲的輸出，不可引用、不可做決定。
- `vlines` 的 `color` 只有 `red` 與 `ink` 兩種（不寫＝ink），要第三種顏色得改鎖定的設計，不要在宣告裡塞色碼。
- `vlines` 的 `at` 必須是 x 欄裡真的存在的值；事件日期沒有資料那一天就標不上去（請把那天補進 csv，或標到相鄰的日期並在判讀說明）。
- 事件線太多會互相疊字，建議 ≤ 5 條；同一天有兩件事請合併成一個 label。
- `sigheat` 至少要兩個數值欄，只有一組請改 `bars` 或 `table`；值必須非負，填帶號 t 值會報「第 N 列的 X 是負的」。
- `sigheat` 的色階兩端是**圖內** min／max，跨圖比較要看數字不能只比深淺；`values:` 計算式選到空白格會報錯，不會默默略過。

### 圖表色彩規則

- 紅 `#c62828` ＝ 重點與「漲」；綠 `#2e7d32` ＝「跌」（東亞慣例）。這份樣張的兩張圖都**沒有**方向色：事件線的紅是「負面事件」不是「漲」，熱圖完全不用紅綠。
- DAU 折線用淡灰細線＋中性藍粗線；熱圖是單一藍色相亮度階（深色格自動改白字），不用彩虹。
- 事件虛線沿用斷點虛線的線型（`.bkline`），顏色走 inline stroke，**沒有新增任何 CSS**。

### 互動說明

折線（[[dau]]）滑過任一天看 DAU 與 MA7，點右側直接標註可切換序列；熱圖（[[sig]]）滑過任一格看指標、族群與 |t|，**沒有序列切換**。事件虛線與事件標籤是靜態 SVG，沒有互動、列印時照樣看得到。觸控裝置 tap 等同 hover。
